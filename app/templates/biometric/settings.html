5-Minute Setup Runbook

1. Install Bridge
Download and copy the RenewalDeskBridge folder onto the gym Windows PC.
2. Register eSSL SDK (One-time)
Right click Register_SDK.cmd and run as Administrator.
3. Update appsettings.json
Fill in GymId (Public ID) and ApiKey from this page, and DeviceIp (e.g. 192.168.1.201).
4. Run Bridge
Execute RenewalDeskBridge.exe. Confirm the green indicator appears.
5. Verify Real Door Lock
Tap Sync Access on any member to confirm the door relay obeys their expiration state.
